# Legacy composition snapshots

These files record the retired `tina_app` / `tina_engine` runtime and its
tests. The documentation consolidation restored them after those packages
and test helpers had been removed. They are preserved here as `.dart.txt`
snapshots so they do not participate in Dart analysis or the current test suite.

They are historical reference material, not executable engine2 integrations.
For the current runtime, see [engine2 architecture](../../../packages/tina_engine_2/README.md)
and [plugin documentation](../../../packages/plugins/README.md).
